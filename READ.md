# Linux Server Health Monitoring Tool

## Project Description

A Bash-based tool to monitor basic Linux server health.

## Features

- Server hostname and current user
- Server uptime
- Disk usage
- Memory usage
- System load
- SSH, Nginx and Docker service status

## Technologies

- Ubuntu Linux
- Bash scripting
- Git
- GitHub

## How to Run

Make the script executable:

chmod +x server-health-check.sh

Run:

./server-health-check.sh

## Learning Outcomes

- Linux commands
- Bash scripting
- Loops and conditions
- Linux service management
- Git version control
